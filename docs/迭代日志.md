## 踩坑备忘(本项目相关)

- bash 下 `mvn` 有 classworlds bug,一律 `bash scripts/mvn.sh`
- PG 表/列 PascalCase 带引号,手写 SQL 必须双引号
- 杀后端要 netstat 找 java PID 强杀,杀 mvn 壳不够
- curl 直连 8081 带 Authorization 会被本地代理吃 → 401;验证走 python urllib 或浏览器 fetch
- 统计测试数用 `grep -E "@Test\b"`,别用 `@Test`(@TestInstance 会误计)
- React 受控输入框 JS 直接 `.value=` 不触发 state,要走 native setter + dispatch input 事件
